# Frontend Plan

## Technology
- React for the dashboard UI.
- A map library such as Leaflet or Mapbox for the forest map.
- Vercel for hosting.

## App structure
- Home dashboard with system summary cards.
- Map view showing all forest zones and sensor pins.
- Zone detail panel with readings and risk level.
- Alert center with active and historical alerts.
- Settings screen for email and threshold preferences.

## UI goals
- Make the data feel live and consistent.
- Keep the map central to the experience.
- Show one clear source of truth for each zone.

## Frontend improvements
- Add a responsive layout for desktop and mobile.
- Use charts for temperature, smoke, and humidity trends.
- Add auto-refresh or live streaming for new readings.
- Keep the visual style clean, modern, and data-focused.
